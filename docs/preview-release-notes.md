## Preview — not a stable end-user release

This preview exists for cross-platform installation and workflow testing. Its native binaries are built and smoke-tested in GitHub Actions, and `checksums.txt` / `checksums.json` are attached so the bootstrapper and npx launcher can verify the downloaded artifact before activation.

The binaries in this preview are unsigned, including Windows executables. Operating-system security warnings are expected. Do not use this preview for sensitive production migration work and do not bypass a warning unless you have independently decided to test this exact checksummed artifact.

Migration OS is local-first and does not upload case data. It is an operational assistant, not legal advice; identity verification, signatures, notarization, payments, and 2FA remain human-only steps.
