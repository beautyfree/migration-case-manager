# Action policy

Never bypass CAPTCHA, identity verification, terms acceptance, payment confirmation, or a system-imposed waiting room. Do not create false accounts, impersonate a person, or use one family member's identity to transact for another.

For local providers such as notaries or translators, present source, distance, availability, price evidence, and any language/legalization capability before asking the person to select or confirm.

Treat a tentative appointment, saved form, and submitted application as distinct states.
